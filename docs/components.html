Components

Everything on this page is CSS. Nothing here needs the behavior layer, and nothing here changes size, so a component is composed by putting classes next to each other rather than by overriding a scale.

Badges

An inverse-video word, padded by one cell either side, so a badge is exactly its label plus two.

Progress

You give cell counts, not percentages: --cells wide with the first --fill filled, and --cells defaults to 24. A percentage would land the fill boundary at 37.4% of a cell, which is the one thing a character grid cannot draw — so the API refuses to accept one.

The track is a ░ run and the fill is a █ run clipped to the filled cells — the same technique as a box border, for the same reason: CSS cannot repeat a glyph a computed number of times.

Alerts

An alert is a box with its border and text tinted. Because the tint is the box's --border variable, every border style works underneath it.

Nav and menu

.nav is a horizontal strip with the current item inverse; .menu is the vertical form, and its selection runs the full width of the column the way a highlighted row does in a TUI. The nav at the top of this page is the first one.

The selected row reaches into the box's gutter cells because .box-tight gave it none to begin with: a highlight that stops one cell short of the border is the kind of near-miss this framework exists to avoid.

Key and value

.kv is a two-column grid on a <dl>, keys dim and in a column as wide as the widest one.

Status bar

A full-width inverse strip, one row tall. .spacer pushes what follows it to the other end, and .statusbar-fixed pins the bar to the bottom of the viewport — which is where the one on this page is, showing the page's size in cells.

A fixed bar is the one element on a webterm page whose position is not on the grid, and it cannot be: it is placed against the viewport, and a viewport is however many pixels tall the window happens to be. Its size is still a whole row, which is what the test suite checks — it measures only the geometry a fixed element actually controls.
