Layout

Three things: a screen that snaps to a whole column count, rows that gutter by one cell, and columns measured in cells rather than twelfths.

The screen

.screen rounds its own width down to a whole number of cells and centers what is left. Everything else assumes it: a child that fills its parent is on the grid because the parent is.

.screen {
  width: calc(round(down, 100%, 1ch));
  margin: 0 auto;
  container-type: inline-size;
}

The rounding is of the parent's resolved width, not of 100vw. 100vw includes the classic scrollbar, so on a page tall enough to scroll the rounded width would be wider than the viewport and the last column would sit underneath the scrollbar.

It is also a container, which is what makes breakpoints in columns possible — see below. For a classic fixed terminal there are .screen-80, .screen-100 and .screen-120.

Rows and columns

A row is a flex row with a one-cell gutter, so N columns lose N−1 cells to gaps. A column is either a fixed number of cells — .col-4 through .col-40 — or .col, which takes what is left.

Mixing a flexible column into a row is where fractional cells get in. One .col beside fixed columns is always safe: the remainder is a whole number because everything taken out of the row was. Two .col children splitting an odd remainder are not — the framework will not stop you, and half a cell is visible at the first border glyph. Prefer fixed widths and one filler.

Breakpoints are columns

Rule 8. A terminal has no pixels to break at, and the number that matters is how many characters fit. Because .screen is a container, a row can ask about its own width in columns instead of asking the viewport about its width in pixels:

@container (max-width: 63ch) {
  .row { display: block; }
  .row > * + * { margin-top: 1lh; }
}

That rule ships: below 64 columns a row stacks, because a 24-column sidebar beside anything is unreadable there. Narrow this window and the example above becomes two stacked boxes — and the column count in the status bar is the number the rule is testing.

Spacing

Spacing is in whole cells, and there are not many helpers because there is not much to choose from: one row or two.

classeffect
.mt-1margin-top: 1lh
.mt-2margin-top: 2lh
.mb-1margin-bottom: 1lh
.mb-2margin-bottom: 2lh
.padpadding: 1lh 1ch
.stackone blank row between children
.centertext-align: center
.righttext-align: right

There is no .mt-3. Three blank rows is not a spacing decision, it is a sign the page wants a box.
