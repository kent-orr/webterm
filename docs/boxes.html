Boxes

Rule 4: a border is a glyph, never border: 1px. That is the rule with the largest consequences, because CSS has no way to repeat a string a computed number of times — so a box cannot simply be told to draw ─ across its top.

The markup

A box needs one empty <span class="box-edge">. An element has two pseudo-elements and a border needs four strips, so the span supplies the other two.

Leave the span out and the box draws only its top and left edges. That is deliberate: a visible reminder beats a silent misalignment.

How the border is drawn

Each edge is one over-long glyph run, clipped to the box by overflow: hidden. Clipping eats the far end of a run, so the four edges are arranged cyclically and each owns the corner at the end it is anchored to:

  ┌─────────▶    top:    anchored left,   owns ┌
  ▲        │     right:  anchored top,    owns ┐
  │        ▼     bottom: anchored right,  owns ┘
  ◀─────────┘    left:   anchored bottom, owns └

Each strip stops one cell short of the next edge's corner, so the four are disjoint: no two glyphs are ever painted into the same cell and no masking is needed. The failure mode is a dropped corner or a missing tail, which geometry cannot see — so the test suite screenshots every box on every page of this site and sweeps the border cells for ink.

The runs cover 256 columns and 128 rows. A box larger than that loses the tail of its border; raise the copy count in src/grid/glyphs.css if you need more.

Border styles

Five, including the ASCII one rule 5 asks for. The style is a class on the box; nothing else changes.

Modifiers

classeffect
.box-titlea label in the top border row
.box-title-rightthe label at the other end
.box-fillfilled interior
.box-tightno gutter, for cell-aligned content
.box-dividea rule across the interior

The title is a real element rather than part of the top run, so it can be bold or colored while the border stays dim. Its background masks the run underneath it, which is also why a filled box has to tell the title what color it is sitting on — .box-fill sets --box-bg for exactly that.

.box-tight drops the one-cell gutter, which is what a table wants: its own padding cells already carry the column separators, so a second gutter would put two blank cells between the border and the first character.

Nesting

A box inside a box loses four cells of width — one border and one gutter on each side — and both are still whole, so nesting is safe to any depth the width allows.
