Theming

A theme sets color custom properties and nothing else. The grid layer names no literal color anywhere — a lint enforces it — so the two layers meet at exactly 22 values and nowhere else.

Both pickers drive this page. The theme swap is one <link> href; the font swap is one class on <html>, and it changes the size of every cell on the page — watch the column count in the status bar.

The contract

:root {
  --bg: ;     --fg: ;
  --cursor: ; --cursor-fg: ;
  --sel: ;    --sel-fg: ;
  --c0: ;  --c1: ;  --c2: ;  --c3: ;
  --c4: ;  --c5: ;  --c6: ;  --c7: ;
  --c8: ;  --c9: ;  --c10: ; --c11: ;
  --c12: ; --c13: ; --c14: ; --c15: ;
}

That is the complete set, all as hex. Copy src/themes/tomorrow-night.css as a starting point. Nine themes ship, and the one this page starts in — Pawpaw — is imported by webterm.css itself, so a page with no theme <link> still paints.

Semantic aliases

Components never name a slot. They name a role, and tokens.css points each role at a slot:

--border: var(--c8);  --muted: var(--c8);
--error: var(--c1);   --ok: var(--c2);
--warn: var(--c3);    --info: var(--c4);
--accent: var(--c5);  --link: var(--c4);

Overriding an alias is legal for every theme except the default. A <link>ed theme declares only its own variables, so an alias that the default set and the next theme does not would survive the swap and tint the new scheme. Several shipped themes do override --muted and --border, because in Tomorrow Night and Solarized Dark --c8 is the background and dim text would otherwise be invisible.

Themes are linted, not eyeballed

test/themes.spec.js checks every theme in two halves, with no browser.

contract
exactly that variable set, as hex, under :root only, and no non-custom property anywhere in the file.
legibility
WCAG ratios for the pairs the grid layer actually paints — 4.5:1 for body text and inverse video, 4:1 for the cursor and selection pairs, 2.5:1 for semantic foregrounds, and 2.4:1 for dim text and box edges, which are meant to recede.

The second half is the one that matters. Inverse video is everywhere in this framework — every heading, badge, status bar and active nav item — so a palette whose background is only nearly legible against its foreground fails in a hundred places at once rather than one. A new theme should pass the lint before it is shipped.

Changing the font size

--wt-font-size is the only px value in the framework, and the line-height derives from it:

:root { --wt-font-size: 20px; }

Each font's --wt-lh-ratio is the largest value that stays seam-free from 10px to 32px, so any size in that range works. 16px is where all four bundled fonts hit their per-size optimum, which is why it is the default.

Changing the size changes nothing else. Every length in the framework is a multiple of a cell, and the cell is derived from the size — so the whole page scales and stays on the grid, which is the one thing a rem-based framework also promises and does not deliver at a border.
