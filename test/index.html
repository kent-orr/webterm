webterm

Every page here is built with the framework it is testing. Served over http so the bundled fonts load — Chromium will not take a @font-face file over file://.

Pages
components.html
Every CSS component, with live font and theme pickers and a cell/row readout. The kitchen sink grid.spec.js measures.
behavior.html
Layer 4: toasts, loading, placeholders and modals, with a motion switch. The page behavior.spec.js measures — including with JavaScript disabled.
default-theme.html
The framework with no theme <link> at all, so the shipped default has to paint it. default.spec.js.
metrics.html
The font calibration harness: line-height limits, seam tests and cell measurement. metrics.spec.js and tools/calibrate.js.
