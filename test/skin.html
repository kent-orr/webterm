components behavior skin

Layer 3, PLAN §12. One link and one class. The skin declares nothing that can move an element: every box on this page is the same box with the glass off, and skin.spec.js measures it.

Glass

The ink is --bg: the ANSI slots are a palette, not a brightness order, so there is no "darkest" token to reach for — --c0 is a light tone in solarized-light. This darkens a dark theme and does nothing to a light one, and never inverts. Set --wt-crt-ink to var(--fg) to see the shape of it.

Cursor

The skin adds the blink and nothing else. The lit cell is .inverse from the grid layer, so with the skin left out a cursor stops blinking rather than disappearing.
